# ADR 0001: Project Name, Identifiers, and Namespace

## Status
Accepted

## Context
The project requires a canonical brand identity, PyPI package name, CLI executable name, and container/filesystem namespace. The system is designed to host African bioinformatics datasets (bacteria, viruses, veterinary/One Health, plant pathogens, parasites, metagenomics) with content-addressable chunk deduplication, Git-based versioning, and open-science community access.

Several candidates were considered:
- `afrihub`: Short and analogous to Hugging Face / Docker Hub.
- `afrigen`: Genomic focus, but slightly narrow given metagenomic, viral, and veterinary datasets.
- `afribio`: Generic acronym.
- `ubuntu-bio`: Centered on the African philosophy of *Ubuntu* ("I am because we are"), reflecting communal collaboration, shared genomic resources, data sovereignty, and open science.

## Decision
We adopt **UbuntuBio** as the project name with the following technical namespace mappings:

- **Formal Project Name**: UbuntuBio (African Bioinformatics Data Hub)
- **PyPI Package Name**: `ubuntu-bio` (importable in Python as `ubuntubio`)
- **CLI Executable**: `ubio` (and alias `ubuntu-bio`)
- **Storage Root Directory**: `/srv/ubuntubio/data/`
- **Default Git Remote URL Pattern**: `https://hub.ubuntubio.org/{owner}/{repo}.git`
- **Default Web Domain**: `ubuntubio.org`
- **Docker Compose Namespace**: `ubuntubio`

## Consequences
- Documentation, configuration templates, environment variable prefixes (`UBUNTUBIO_*`), and schema definitions will use this consistent naming convention.
- Storage folder path across all deployment documentation is standardized to `/srv/ubuntubio/data/`.
